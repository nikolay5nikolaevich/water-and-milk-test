# Расчёт заказа поставщикам

Программа получает остатки товаров и считает, сколько единиц каждого товара заказать.
Работает двумя способами: из командной строки (Node.js) и как сайт (Vite, хостинг на Vercel).

Инструкция для пользователей без технических подробностей лежит в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Формула

```
Период покрытия   = lead_days + 7
Целевой запас     = ⌈daily_sales × период покрытия + safety_stock⌉
Доступно          = stock + incoming
Заказ             = max(0, целевой запас − доступно)
```

Вся логика лежит в одном файле: [src/calc.js](src/calc.js) (функция `calcOrder`, константа `COVER_DAYS`).
Сайт и CLI используют один и тот же модуль.

Про округление: в JS `0.1 × 30 = 3.0000000000000004`, и простой `Math.ceil` дал бы 4 вместо 3.
Поэтому перед округлением вверх вычитается `1e-9`.

## Запуск

Нужен Node.js 18+ (для тестов ещё Python 3.9+).

```bash
npm install
npm run calc                                   # расчёт по data/products.csv
node cli.js data/invalid.csv                   # другой файл
node cli.js data/products.csv --out report.csv # сохранить отчёт (CSV, открывается в Excel)
node cli.js data/products.csv --json           # машиночитаемый вывод
npm run dev                                    # сайт локально: http://localhost:5173
npm test                                       # тесты (Python)
```

На сайте можно переключаться между примером, примером с ошибками и своим CSV, править данные прямо на странице
(расчёт пересчитывается сразу), показать только позиции к заказу и скачать отчёт.
Ссылка `/?data=invalid` сразу открывает пример с ошибками.

## Входные данные

CSV с заголовком `sku,name,stock,daily_sales,incoming,lead_days,safety_stock`.
Принимается и разделитель `;` с десятичной запятой (так сохраняет Excel в русской локали).

Проверка строк: `stock`, `incoming`, `lead_days`, `safety_stock` должны быть целыми ≥ 0,
`daily_sales` должно быть числом ≥ 0, `sku` уникален и не пуст, `name` не пусто, число столбцов совпадает с заголовком.
Некорректные строки **исключаются из расчёта** и выводятся отдельным списком с номером строки и причиной.
Если такие строки есть, CLI завершается с кодом 1.

- [data/products.csv](data/products.csv): пример из задания
- [data/invalid.csv](data/invalid.csv): пример с ошибками

## Тесты

[tests/reference.py](tests/reference.py) — независимая реализация на Python (через `Decimal`, без погрешностей float),
её же можно запускать как проверку файла: `python tests/reference.py data/products.csv`.

[tests/test_orders.py](tests/test_orders.py) запускает `node cli.js --json` и сверяет результат:
- с ожидаемыми числами по `products.csv`;
- с граничными случаями: заказ не нужен, нулевые продажи, товар в пути, дробные продажи, ловушка float-округления;
- со списком ошибок на `invalid.csv`, а также с форматом `;` и десятичной запятой;
- с эталоном на 2000 случайных товаров.

## Деплой

Репозиторий подключается к Vercel как есть: фреймворк Vite определяется автоматически,
команда сборки `npm run build`, папка вывода `dist`.
